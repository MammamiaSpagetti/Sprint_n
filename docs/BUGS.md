Стенд: https://qa-routes.education-services.ru/

## BUG-001 — перепутаны описания «Сонный» и «Разговорчивый»

Предусловия: ввести «Хамовнический Вал, 34» и «Зубовский бульвар, 37», выбрать «Быстрый», нажать «Вызвать такси».

Шаги:

1. Выбрать тариф «Сонный».
2. Навести курсор на его иконку `i`.
3. Сравнить описание с ТЗ.
4. Повторить для тарифа «Разговорчивый».

| Тариф | Ожидается по ТЗ | Фактически |
| --- | --- | --- |
| Сонный | Для тех, кто не выспался | Если мысли не выходят из головы |
| Разговорчивый | Если мысли не выходят из головы | Для тех, кто не выспался |

Автотест: `TestTaxiTariffs.test_sleepy_and_talkative_descriptions_match_specification`, два параметризованных случая. Оба помечены `xfail(strict=True, raises=AssertionError)`; ожидаемые строки не заменены фактическими.

Воспроизведение как настоящих падений:

```powershell
.\.venv\Scripts\python.exe -m pytest test/test_taxi_tariffs.py -k sleepy_and_talkative --runxfail
```

Скриншоты наведённых подсказок и HTML приложены к соответствующим тестам в Allure.
